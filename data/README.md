# Data

This directory contains documentation related to the datasets used by CYCLONE-X.

## Planned Data Sources

- NOAA IBTrACS
- NOAA HURSAT
- ISRO MOSDAC
- IMD / RSMC New Delhi

Raw datasets are not committed to this repository unless their licenses and distribution terms permit it.

## Data Pipeline

Raw Satellite Data
→ Preprocessing
→ Quality Control
→ Geo-Alignment
→ Data Fusion
→ Model Input
