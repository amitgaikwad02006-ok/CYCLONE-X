# Source Code

This directory contains the core implementation of CYCLONE-X.

## Planned Modules

- `preprocessing/` — Satellite data cleaning, normalization and geo-alignment
- `data_fusion/` — Multi-source data integration
- `models/` — AI/ML model implementations
- `classification/` — Cyclone pattern classification
- `prediction/` — Cyclone pattern evolution and prediction
- `visualization/` — Model outputs and visualizations

The implementation will be added as the project develops.
