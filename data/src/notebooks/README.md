# Notebooks

This directory contains Jupyter notebooks used for data exploration, preprocessing experiments, model development, and evaluation.

## Planned Notebooks

- `01_data_exploration.ipynb` — Explore and understand the satellite/cyclone data
- `02_preprocessing.ipynb` — Experiment with data preprocessing
- `03_model_training.ipynb` — Model development and training
- `04_model_evaluation.ipynb` — Evaluate model performance

Experiments and results will be added as the project develops.
